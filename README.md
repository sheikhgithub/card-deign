# 📋 Dynamic Price Card UI

This is a simple and responsive card UI project built using only **HTML**, **CSS**, and **JavaScript**. It dynamically renders cards from a JavaScript array of objects (`cardData`) — no frameworks or libraries used.

---

## ✨ Features

- 🔹 Dynamic rendering of cards using plain JavaScript
- 🔹 Hover effect on individual cards
- 🔹 Status-based content display (LIVE, EXPIRED, NEXT)
- 🔹 Clean and responsive design
